🖥️ Speedtest CLI

Run speed tests from your terminal. Install the official Ookla CLI:

# macOS
brew install speedtest-cli
# Linux
curl -s https://packagecloud.io/install/repositories/ookla/speedtest-cli/script.deb.sh | sudo bash
sudo apt install speedtest
# Test a specific server
speedtest -s SERVER_ID

🔧 Server Search API

Ookla's public server search endpoint you can query directly:

https://www.speedtest.net/api/js/servers?engine=js&search=QUERY&limit=20

Returns JSON with id, name, sponsor, host, country, lat, lon, distance fields.
